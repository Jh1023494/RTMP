# 작업 지시서: 테마 프리셋 관리자 도움말 문구 쓰기

## 목표

RisuAI 플러그인 "테마 프리셋 관리자" 화면의 각 UI 항목에 붙일 도움말 문구를 한국어로 쓴다. 코드는 다른 사람이 짠다. 너는 문구만 쓴다.

## 배경

- RisuAI는 AI 채팅 앱이다. 사용자는 Custom HTML과 Custom CSS 설정으로 채팅 메시지의 모양(테마)을 바꿀 수 있다.
- 이 플러그인은 그 HTML·CSS 묶음을 "프리셋"으로 여러 개 저장해 두고, 고르고, 미리 보고, RisuAI에 적용하게 해 준다.
- 관리자 화면에는 `?` 버튼으로 켜는 "도움말 모드"가 생긴다. 도움말 모드에서 항목을 누르면 그 항목의 실제 동작은 일어나지 않고 설명 상자만 뜬다. PC에서는 도움말 모드가 아닐 때도 마우스를 올리면 한 줄 설명이 뜬다.
- 읽는 사람은 RisuAI로 채팅은 해 봤지만 HTML, CSS, 정규식, CBS를 모르거나 잘 모르는 사람이다. 휴대폰 사용자가 많다.

## 결과물

프로젝트 폴더 `risu-theme-preset-v3` 안에 아래 두 파일을 만든다. 다른 파일은 고치지 않는다.

1. `docs/help-copy.json`
2. `docs/help-copy-notes.md`: 동작이 아래 사실 목록만으로 분명하지 않아 질문이 남은 항목, 또는 용어를 바꾸자고 제안할 것이 있을 때만 적는다. 없으면 "없음" 한 줄을 쓴다.

`help-copy.json`의 형식은 다음과 같다. 키는 아래 "항목 목록"의 키를 빠짐없이, 같은 순서로 쓴다.

```json
{
  "tb.save": {
    "short": "...",
    "long": "..."
  }
}
```

- `short`: 마우스를 올렸을 때 뜨는 한 줄이다. 30자 이내로 쓴다.
- `long`: 도움말 모드에서 뜨는 설명이다. 1~3문장, 150자 이내로 쓴다. "무엇을 하는가"를 먼저 쓰고, 필요하면 "언제 쓰는가"나 "주의할 점"을 붙인다.
- 항목 목록에 `short만`이라고 적힌 키는 `long`을 빈 문자열로 둔다.

## 쓰는 규칙

### 내용

- 아래 "항목 목록"의 사실만 쓴다. 목록에 없는 기능, 동작, 수치는 지어내지 않는다. 사실이 부족해 문장을 쓸 수 없으면 `help-copy-notes.md`에 질문으로 남기고, 그 항목에는 확실한 부분만 쓴다.
- 각 설명은 다른 설명을 읽지 않은 사람도 이해할 수 있어야 한다. 낯선 용어(Custom HTML, CSS, 정규식, CBS, 플래그, 접두사 등)를 쓰면 같은 설명 안에서 짧게 풀어 준다. 풀이가 설명보다 길어지면 그 용어를 쓰지 않고 하는 일로 바꿔 말한다.
- 버튼 이름을 그대로 되풀이하는 설명은 쓰지 않는다. 그 버튼을 누르면 무엇이 바뀌는지 쓴다.
- 되돌릴 수 없는 동작(삭제, 목록 교체, 복원)은 `long`에 그 사실을 쓴다.
- 비유와 과장을 쓰지 않는다.

### 용어

한 용어는 모든 설명에서 같은 말로 쓴다. 아래 용어는 이대로 쓴다.

| 쓸 말 | 뜻 |
| --- | --- |
| 프리셋 | 이름, 메모, Custom HTML, Custom CSS, 디스플레이 정규식 규칙을 묶은 저장 단위 |
| 적용 | 프리셋의 HTML·CSS를 RisuAI 설정에 써서 채팅 화면에 입히는 것 |
| 원래 테마 | 이 플러그인으로 처음 적용하기 직전의 RisuAI 테마 설정. 플러그인이 따로 보관한다 |
| 저장 | 편집한 내용을 플러그인의 프리셋 목록에 기록하는 것. 저장만 해서는 RisuAI 화면이 바뀌지 않는다 |
| 디스플레이 정규식 | 채팅에 보이는 글자만 바꾸는 규칙. 저장된 대화 내용은 바뀌지 않는다 |
| 클립보드 | 복사한 내용이 붙여넣기 전까지 머무는 곳 |

### 문장

- 합니다체로 쓴다. `short`도 "~합니다", "~입니다"로 맺는 한 문장으로 쓴다.
- 주어가 분명하면 생략한다. "이 버튼은", "이 기능은"으로 시작하지 않는다.
- 번역투를 쓰지 않는다.

  | 번역투 | 고침 |
  | --- | --- |
  | ~하는 것입니다 | ~합니다 |
  | ~로부터, ~에 대해/대한, ~을 위한 | ~에서, ~을/를로 바꾸거나 문장을 다시 짠다 |
  | ~하도록 ~합니다 (so that 직역) | 한국어 어순으로 다시 짠다 |
  | 무생물 주어 ("이 버튼이 ~을 가능하게 합니다") | 사람이나 행위를 주어로 쓴다 |

- 명사와 동사는 실제로 함께 쓰는 짝으로 고른다. 영어를 옮긴 말보다 한국어가 원래 쓰는 말을 고른다.
- 화면에 보이는 버튼 이름은 작은따옴표 없이 그대로 쓴다. 따옴표가 필요하면 `‘ ’`를 쓴다.
- 넘기기 전에 오타, 맞춤법, 띄어쓰기를 다시 읽는다.

## 화면 구성

```
[헤더]   테마 프리셋 관리자 · (적용 상태 배지)                    [?] [닫기]
[휴대폰에서만]  목록 | 편집 | 미리보기
[목록 열]  검색칸 / 프리셋 카드들
[편집 열]  [+ 새 프리셋] [저장] [삭제]          [RisuAI에 적용] [⋯]
           탭: HTML · CSS | 정규식
           (HTML · CSS 탭) 이름, 메모, 검증 배지, Custom HTML 편집창, Custom CSS 편집창
           (정규식 탭) 디스플레이 정규식 규칙 / HTML·CSS 일괄 변환 / Regex OUT 템플릿 변환
[미리보기 열]  너비 버튼 / 배색 버튼 / 보일 메시지 버튼 / 샘플 설정(접힘) / 미리보기 화면
```

넓은 화면에서는 세 열이 나란히 보인다. 휴대폰에서는 `목록 | 편집 | 미리보기` 탭으로 한 열씩 본다.

## 항목 목록

각 줄은 `키` — 화면에 보이는 이름 — 사실 순서다.

### 헤더

- `help.toggle` — `?` 버튼 — 도움말 모드를 켜고 끈다. 켜져 있는 동안 항목을 누르면 실제 동작 대신 설명이 뜬다. Esc로도 끈다.
- `help.banner` — 도움말 모드가 켜지면 헤더 아래에 뜨는 안내 띠 — **short만.** 항목을 누르면 설명이 나온다는 것과, 끝내려면 `?`나 Esc를 누른다는 것을 알린다.
- `header.status` — "적용 중: 프리셋 이름" 또는 "RisuAI 기본 설정 사용 중" 배지 — 지금 RisuAI에 이 플러그인으로 적용한 프리셋이 무엇인지 보여 준다. 적용한 프리셋이 없으면 RisuAI 자체 설정을 쓰는 중이다.
- `header.close` — 닫기 — 관리자 창을 닫는다. 저장하지 않은 편집 내용은 창을 다시 열면 그대로 남아 있다. RisuAI를 새로 고치면 사라진다.

### 휴대폰 탭

- `mnav.list` — 목록 — 프리셋 목록 화면으로 바꾼다.
- `mnav.editor` — 편집 — 선택한 프리셋의 편집 화면으로 바꾼다.
- `mnav.preview` — 미리보기 — 편집 중인 프리셋이 채팅에서 어떻게 보일지 보여 주는 화면으로 바꾼다.

### 목록

- `list.search` — 검색칸 — 프리셋 이름과 메모에서 입력한 글자를 찾아 목록을 거른다.
- `list.card` — 프리셋 카드 — 누르면 그 프리셋을 편집 열에 연다. 저장하지 않은 변경이 있으면 저장할지 먼저 묻는다. 카드에는 이름과 메모 첫 줄이 보인다.
- `list.badge-active` — 카드의 "적용 중" 배지 — 이 프리셋이 지금 RisuAI에 적용되어 있다.
- `list.badge-unsaved` — 카드의 "저장 안 됨" 배지 — 새로 만들고 아직 한 번도 저장하지 않은 프리셋이다. 저장하지 않고 다른 프리셋을 열면 사라진다.
- `list.dirty-dot` — 카드 이름 옆의 노란 점 — 편집했지만 아직 저장하지 않은 변경이 있다.

### 편집 열 버튼

- `tb.new` — + 새 프리셋 — 이름, 메모, 비어 있는 HTML·CSS 칸을 가진 새 프리셋을 연다. 저장을 누르기 전에는 목록에 기록되지 않는다.
- `tb.save` — 저장 / 저장 • / 저장됨 — 편집한 내용을 프리셋 목록에 기록한다. 바뀐 내용이 없으면 "저장됨"으로 흐리게 보이고 눌리지 않는다. 바뀐 내용이 있으면 "저장 •"으로 보인다. Ctrl+S(맥은 Cmd+S)로도 저장한다. 저장만 해서는 RisuAI 화면이 바뀌지 않는다.
- `tb.delete` — 삭제 — 지금 연 프리셋을 목록에서 지운다. 한 번 확인을 묻는다. 지운 프리셋은 되살릴 수 없다. 이미 RisuAI에 적용된 HTML·CSS는 지워도 그대로 남는다. 저장하지 않은 새 프리셋이면 버리기만 한다.
- `tb.apply` — RisuAI에 적용 / RisuAI에 다시 적용 — 지금 프리셋을 저장한 뒤 그 HTML·CSS를 RisuAI의 Custom HTML·CSS 설정에 써서 채팅 화면에 입힌다. 처음 적용할 때 원래 테마를 따로 보관한다. 처음 적용할 때 RisuAI가 데이터베이스 읽기·쓰기 권한을 물으며, 허용해야 적용된다. 검증 오류가 있으면 그래도 적용할지 묻는다.
- `tb.more` — ⋯ — 자주 쓰지 않는 기능을 모은 메뉴를 연다.

### ⋯ 메뉴

- `menu.duplicate` — 복제 — 지금 프리셋을 "(복사본)"이 붙은 이름으로 새로 저장하고 연다. 저장하지 않은 변경이 있으면 원본을 먼저 저장한다.
- `menu.export-json` — JSON 내보내기 (복사) — 지금 프리셋 전체(이름, 메모, HTML, CSS, 정규식 규칙)를 JSON 글로 클립보드에 복사한다. 다른 기기나 다른 사람에게 그대로 옮길 때 쓴다. 복사가 막히면 내용을 띄워 직접 복사하게 한다.
- `menu.paste-json` — JSON 붙여넣기 — 붙여넣을 칸을 연다. 프리셋 JSON이면 새 프리셋으로 추가한다. 같은 프리셋이 이미 있으면 그 프리셋을 덮어쓴다. Risu 정규식 JSON이면 지금 프리셋의 규칙 뒤에 붙인다. "기존 목록을 지우고 이 내용으로 바꾸기"를 체크하면 지금 목록을 모두 지우고 붙여넣은 내용으로 바꾼다(전체 백업을 되살릴 때 쓴다).
- `menu.file-import` — 파일 불러오기 (.json) — `.json` 파일을 골라 JSON 붙여넣기와 같은 방식으로 가져온다. 여러 파일을 한 번에 고를 수 있다.
- `menu.backup-all` — 전체 백업 복사 — 모든 프리셋을 한 JSON 글로 클립보드에 복사한다. 메모장 등에 붙여넣어 보관해 두었다가 JSON 붙여넣기로 되살린다.
- `menu.capture` — 현재 설정 가져오기 — 지금 RisuAI에 들어 있는 Custom HTML·CSS를 새 프리셋으로 저장한다. 플러그인을 쓰기 전에 만들어 둔 테마를 목록에 넣을 때 쓴다.
- `menu.restore` — 원래 테마로 복원 — 확인을 받은 뒤 RisuAI 테마 설정(theme, Custom HTML, Custom CSS)을 원래 테마로 되돌린다. 프리셋 목록은 그대로 남고, "적용 중" 표시는 사라진다. 보관한 원래 테마가 없으면 아무것도 바꾸지 않는다. 플러그인을 지우기 전에 원래 모습으로 돌아가고 싶을 때 쓴다.

### 탭

- `tab.editor` — HTML · CSS — 이름, 메모, Custom HTML, Custom CSS를 편집하는 탭으로 바꾼다.
- `tab.regex` — 정규식 / 정규식 (개수) — 디스플레이 정규식 규칙과 HTML·CSS 일괄 변환 도구가 있는 탭으로 바꾼다. 괄호 안 숫자는 규칙 개수다.

### HTML · CSS 탭

- `ed.name` — 이름 — 프리셋 이름이다. 목록과 "적용 중" 배지에 보인다. 비워 두고 저장하면 "이름 없는 프리셋"이 된다.
- `ed.memo` — 메모 — 프리셋에 붙이는 자유 메모다. 여러 줄을 쓸 수 있고, 목록 카드에는 첫 줄만 보인다. JSON으로 내보내면 함께 옮겨진다.
- `ed.validation` — 검증 배지와 목록 — HTML·CSS가 RisuAI에서 제대로 동작할지 자동으로 점검한 결과다. "오류"는 적용하면 메시지가 제대로 보이지 않을 수 있는 문제이고, "경고"는 동작은 하지만 고치는 편이 나은 점이다. 편집하면 바로 다시 점검한다. 점검 항목: 본문 자리 `<risutextbox></risutextbox>`가 없음, 특수 태그를 `<risuicon/>`처럼 한 태그로 닫음, CBS 블록의 여닫기가 맞지 않음, `<img>`·`<script>`·HTML 안의 `<style>` 사용, 구형 `{{#if}}` 문법 사용.
- `ed.html` — Custom HTML 편집창 — 채팅 메시지 하나하나의 틀을 정하는 HTML이다. 본문이 들어갈 자리에 `<risutextbox></risutextbox>`를 넣는다. 아바타는 `<risuicon></risuicon>`, 메시지 버튼은 `<risubuttons></risubuttons>`, 생성 정보는 `<risugeninfo></risugeninfo>` 자리에 들어간다. 이 특수 태그들은 반드시 닫는 태그까지 쓴다. `{{char}}`(캐릭터 이름), `{{user}}`(사용자 이름), `{{#when::{{role}}::is::char}}…{{/when}}`(캐릭터 메시지일 때만 보이기) 같은 CBS 문법을 쓸 수 있다. Tab은 공백 2칸 들여쓰기, Shift+Tab은 내어쓰기다.
- `ed.css` — Custom CSS 편집창 — 색, 크기, 간격 같은 모양을 정하는 CSS다. RisuAI 전체 화면에 적용되므로 클래스 이름에 고유한 접두사를 붙이는 편이 안전하다. Tab 동작은 HTML 편집창과 같다.
- `ed.copy` — 편집창 이름표 옆의 복사 — 그 편집창의 코드만 클립보드에 복사한다. RisuAI 설정에 직접 붙여넣거나 남에게 코드만 줄 때 쓴다.

### 정규식 탭: 디스플레이 정규식 규칙

- `rx.rules` — 디스플레이 정규식 규칙 상자 — 이 프리셋에 딸린 글자 바꾸기 규칙들이다. RisuAI에 적용된 프리셋의 켜진 규칙만 채팅 표시에 쓰인다. 저장된 대화 내용은 바뀌지 않는다. 플러그인을 지우면 규칙도 함께 꺼진다. 미리보기에도 반영된다.
- `rx.paste` — Risu 정규식 붙여넣기 — JSON 붙여넣기 칸을 연다. RisuAI에서 내보낸 정규식 스크립트(JSON)를 붙여넣으면 이 프리셋의 규칙 뒤에 붙는다.
- `rx.copy` — Risu 정규식 복사 — 이 프리셋의 규칙을 RisuAI 정규식 스크립트 형식(JSON)으로 클립보드에 복사한다. RisuAI의 정규식 설정에서 가져올 수 있다. 규칙이 없으면 눌리지 않는다.
- `rx.add` — + 규칙 추가 — 빈 규칙 하나를 맨 뒤에 추가한다.
- `rx.host-toggle` — "적용 중인 프리셋의 규칙을 RisuAI 채팅에 씁니다" 체크 — 끄면 적용 중인 프리셋의 규칙을 채팅에 쓰지 않는다. 프리셋과 상관없는 플러그인 전체 설정이며 바로 반영된다. RisuAI 플러그인 설정 화면의 같은 항목과 연결되어 있다.
- `rx.rule-enable` — 규칙 카드의 체크 — 이 규칙 하나를 켜고 끈다. 꺼진 규칙은 흐리게 보이고 채팅과 미리보기에 쓰이지 않는다.
- `rx.rule-name` — 규칙 이름 — 규칙을 알아보기 위한 이름이다. 동작에는 영향이 없다.
- `rx.rule-flag` — 플래그 — 정규식 검색 방식을 정하는 글자들이다. `g`는 모두 찾기, `i`는 대소문자 무시, `m`은 줄마다 처음과 끝 맞추기, `s`는 `.`이 줄바꿈도 포함하기다.
- `rx.rule-move` — ↑ ↓ — 규칙 순서를 바꾼다. 규칙은 위에서부터 차례로 적용된다.
- `rx.rule-delete` — 규칙 카드의 삭제 — 이 규칙을 지운다. 확인을 묻지 않는다. 저장하기 전이면 다른 프리셋으로 넘어갈 때 변경을 버려서 되돌릴 수 있다.
- `rx.rule-in` — IN — 찾을 글자 패턴(정규식)이다.
- `rx.rule-out` — OUT — 찾은 부분을 바꿀 내용이다. `$&`는 찾은 글자 전체, `$1`은 패턴에서 첫 번째 괄호로 묶은 부분이다.

### 정규식 탭: HTML·CSS 일괄 변환

- `rx.bulk` — HTML·CSS 일괄 변환 상자 — 편집 중인 HTML·CSS를 규칙에 따라 한꺼번에 고친다. 저장하기 전까지는 확정되지 않는다.
- `rx.legacy-when` — {{#if}} → {{#when}} — 캐릭터·사용자 메시지를 나누는 구형 CBS 조건문 `{{#if {{equal::{{role}}::char}}}}…{{/if}}`(및 `not_equal`)을 신형 `{{#when::{{role}}::is::char}}…{{/when}}`(및 `isnot`)으로 바꾼다. HTML에만 적용된다.
- `rx.fix-selfclose` — 자기닫힘 슬롯 고치기 — `<risuicon/>`처럼 한 태그로 닫은 특수 태그를 `<risuicon></risuicon>`으로 바꾼다. RisuAI는 한 태그로 닫은 특수 태그를 제대로 읽지 못한다. HTML에만 적용된다.
- `rx.prefix` — 기존 접두사 → 새 접두사, 접두사 바꾸기 — HTML의 클래스 이름, CSS의 클래스 선택자·변수(`--`로 시작하는 이름)·애니메이션 이름에서 기존 접두사로 시작하는 이름을 새 접두사로 한꺼번에 바꾼다. 두 칸 중 하나라도 비었거나 두 값이 같으면 바꾸지 않는다. 다른 테마의 클래스 이름과 겹치지 않게 할 때 쓴다.
- `rx.custom` — HTML만/CSS만/HTML+CSS 선택, 찾을 정규식, 플래그, 바꿀 내용, 실행 — 직접 쓴 정규식으로 고른 대상을 한꺼번에 찾아 바꾼다. 플래그를 비우면 `g`(모두 찾기)로 처리한다. 바꿀 내용에 `$1` 등을 쓸 수 있다. 몇 곳을 바꿨는지 알려 준다.

### 정규식 탭: Regex OUT 템플릿 변환

- `rx.outconv` — Risu Regex OUT 템플릿을 HTML·CSS로 (입력칸과 변환해서 넣기) — RisuAI 정규식의 OUT 칸으로 만든 테마를 Custom HTML로 옮긴다. 본문 자리 표시(`{{data}}`, `$&`, `$1` 중 처음 찾은 것)는 `<risutextbox></risutextbox>`로 바뀐다. 본문 자리 표시가 없으면 끝에 `<risutextbox></risutextbox>`를 붙이고 알려 준다. 한 태그로 닫은 특수 태그와 구형 `{{#if}}` 조건문도 함께 고친다. HTML 편집창은 변환 결과로 덮어쓰고, `<style>` 안의 CSS는 기존 CSS 뒤에 붙인다. 저장하기 전까지는 확정되지 않는다.

### 미리보기

- `pv.width` — 전체 / 창 / 모바일 — 미리보기 화면의 폭을 바꾼다. 전체는 미리보기 열을 꽉 채우고, 창은 520px, 모바일은 390px이다.
- `pv.palette` — 다크 / 라이트 — RisuAI 앱이 어두운 배색일 때와 밝은 배색일 때를 흉내 낸다. RisuAI의 실제 설정은 바꾸지 않는다.
- `pv.role` — 모두 / 캐릭터 / 사용자 / 편집 중 — 미리보기에 보일 메시지를 고른다. 편집 중은 메시지를 고치는 중일 때의 모습이다.
- `pv.sample` — 샘플 설정 — 누르면 펼쳐진다. 미리보기에 쓰는 이름, 글자 크기, 샘플 메시지, 정규식 반영 여부를 바꾼다. 모두 미리보기에만 쓰이고 프리셋에는 저장되지 않는다.
- `pv.names` — 캐릭터 이름, 사용자 이름 — 미리보기에서 `{{char}}`, `{{user}}` 자리에 들어갈 이름이다. 비우면 기본 이름을 쓴다.
- `pv.fontsize` — 글자 px — 미리보기 화면의 기본 글자 크기다. 10~28 사이 값을 받는다.
- `pv.sample-text` — 샘플 메시지 — 미리보기 메시지 본문에 넣을 글이다. 비우면 강조, 대사, 목록, 코드가 섞인 기본 샘플을 쓴다.
- `pv.apply-regex` — 이 프리셋의 디스플레이 정규식도 적용 — 체크하면 이 프리셋의 켜진 규칙을 미리보기 메시지에 반영한다.
- `pv.frame` — 미리보기 화면 — 편집 중인 HTML·CSS를 RisuAI 채팅과 비슷한 환경에서 보여 준다. 저장하지 않은 내용도 바로 반영된다. 실제 RisuAI 화면과 조금 다를 수 있으므로 마지막 확인은 적용한 뒤 채팅에서 한다.

## 끝났을 때의 모습

- `docs/help-copy.json`이 올바른 JSON이고, 위 항목 목록의 키 59개가 빠짐없이 같은 순서로 들어 있다.
- 모든 `short`는 30자 이내이고, `help.banner`를 뺀 모든 `long`은 1~3문장, 150자 이내다.
- 항목 목록에 없는 기능이나 동작을 쓰지 않았다.
- 용어 표의 말을 모든 설명에서 같은 뜻으로 썼다.
- `docs/help-copy-notes.md`가 있다.
