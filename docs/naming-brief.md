# 작업 지시서: 테마 프리셋 이름 검토

## 목표

RisuAI 플러그인 "테마 프리셋 관리자"에 기본으로 들어가는 프리셋 31개의 이름을 검토한다. 지금 정한 이름 체계가 쓰는 사람에게 잘 읽히는지 판단하고, 약한 이름에는 대안을 낸다. 코드는 고치지 않는다. 의견만 쓴다.

## 배경

- RisuAI는 AI 채팅 앱이다. 사용자는 Custom HTML과 Custom CSS로 채팅 메시지의 모양(테마)을 바꾼다.
- 이 플러그인은 테마를 "프리셋"으로 저장해 두고 골라 쓰게 한다. 프리셋은 목록에서 "그룹"으로 묶인다. 그룹은 접고 펼 수 있는 폴더다.
- 목록 카드에는 프리셋 이름 한 줄과 메모 첫 줄이 보인다. 카드 폭은 PC에서 약 230px, 휴대폰에서는 화면 폭이다. 이름이 길면 말줄임표로 잘린다.
- 목록 위에 검색칸이 있다. 이름과 메모에 든 글자로 찾는다.
- 쓰는 사람은 RisuAI로 캐릭터와 대화하는 사람이다. HTML·CSS를 모르는 사람이 많고 휴대폰 사용자가 많다.

## 프리셋 구성

프리셋은 세 가지 대상을 생각해 만들었다. 대상마다 화면 구조가 다른 분류가 있고, 분류 안에는 색이나 소재만 다른 변주가 3개씩 있다.

| 대상 | 분류 | 화면이 무엇처럼 보이는가 |
| --- | --- | --- |
| 소설을 읽듯 몰입 | 서재 | 종이책 페이지. 카드와 아바타 없이 문단이 이어지고, 캐릭터 서술 앞에 장 구분 기호(⁂)가 붙는다. 사용자 입력은 들여쓴 흐린 메모 |
| 소설을 읽듯 몰입 | 연재란 | 웹소설 앱 화면. 고딕 글꼴, 넓은 문단 간격. 사용자 입력은 오른쪽에 붙는 둥근 선택지 |
| 캐릭터에 애정 | 메신저 twin | 메신저 말풍선. 모든 메시지 양옆에 캐릭터와 사용자 이미지가 둘 다 있다 |
| 캐릭터에 애정 | 메신저 solo | 메신저 말풍선. 보낸 쪽 이미지만 있다. 캐릭터는 큰 세로 초상, 사용자는 작은 원형 |
| 캐릭터에 애정 | 편지 twin | 줄 쳐진 편지지. 머리에 "From. 보낸 사람 ✉ To. 받는 사람"과 두 사람 초상 |
| 캐릭터에 애정 | 편지 solo | 줄 쳐진 편지지. 머리에 보낸 쪽 초상과 "From. 이름". 사용자 답장은 작은 쪽지 |
| 세계에 이입 | 양피지 | 판타지. 얼룩진 양피지, 밀랍 인장 모양 아바타 테두리, "이름의 기록" 머리글, 장식 첫 글자 |
| 세계에 이입 | 디스플레이 | SF. 우주선 화면의 통신 기록. 주사선, 모서리 표식, "TRANSMISSION // 이름" 머리글 |
| 세계에 이입 | 파일 | 현대·느와르. 수사 파일. 파일 탭, 비스듬한 증명사진, 붉은 도장 |
| 세계에 이입 | 한지 | 동양풍. 한지 결, 세로 띠 이름표, 낙관 모양 아바타 테두리 |

이 밖에 따로 설계한 "에코 (글래스 메신저)" 프리셋이 하나 있다. 이 프리셋은 검토 대상이 아니다.

## 지금 정한 이름 체계

- 형식은 `그룹:이름`이다. 콜론 앞이 그룹 이름이고, 같은 앞부분을 가진 프리셋은 한 그룹에 묶인다.
- 메신저와 편지는 이미지 배치를 `twin`(두 사람 모두) / `solo`(보낸 쪽만)로 나눈다.
- 대상 이름(소설 읽기, 애정, 세계관)은 이름에 넣지 않고 메모 첫 줄에 쓴다. 메모 첫 줄 형식은 "대상 · 분류 · 변주"다.

| 그룹 | 프리셋 이름 |
| --- | --- |
| 서재 | 서재:크림, 서재:세피아, 서재:밤 |
| 연재란 | 연재란:다크, 연재란:화이트, 연재란:블루그레이 |
| 메신저 | 메신저:twin 핑크, 메신저:twin 민트, 메신저:twin 미드나잇, 메신저:solo 핑크, 메신저:solo 민트, 메신저:solo 미드나잇 |
| 편지 | 편지:twin 크림, 편지:twin 하늘, 편지:twin 라벤더, 편지:solo 크림, 편지:solo 하늘, 편지:solo 라벤더 |
| 양피지 | 양피지:황토, 양피지:숲, 양피지:진홍 |
| 디스플레이 | 디스플레이:청록, 디스플레이:적색, 디스플레이:백색 |
| 파일 | 파일:흑백, 파일:세피아, 파일:네온 |
| 한지 | 한지:먹, 한지:청자, 한지:단청 |

변주가 실제로 어떤 모습인지는 아래와 같다.

| 프리셋 | 모습 |
| --- | --- |
| 서재:크림 / 세피아 / 밤 | 밝은 크림 종이 / 누렇게 바랜 종이 / 어두운 바탕에 회백색 글자 |
| 연재란:다크 / 화이트 / 블루그레이 | 검은 바탕 / 흰 바탕 / 푸른 기가 도는 어두운 회색 바탕 |
| 메신저의 핑크 / 민트 / 미드나잇 | 연분홍 / 연한 민트 / 짙은 남색 바탕 |
| 편지의 크림 / 하늘 / 라벤더 | 크림색 편지지 / 하늘색 줄노트 / 연보라 편지지 |
| 양피지:황토 / 숲 / 진홍 | 누런 양피지에 붉은 인장 / 녹색 기가 도는 양피지에 금색 장식 / 검붉은 바탕에 금색 장식 |
| 디스플레이:청록 / 적색 / 백색 | 어두운 화면에 청록 빛 / 어두운 화면에 붉은 경보 빛 / 밝은 흰 화면에 파란 글자 |
| 파일:흑백 / 세피아 / 네온 | 회백색 종이와 흑백 사진 / 누런 신문지와 세피아 사진 / 어두운 바탕에 분홍 네온 |
| 한지:먹 / 청자 / 단청 | 한지에 검은 띠 / 옥색 띠 / 붉은 띠와 위쪽 단청 무늬 |

## 할 일

1. **이름 체계 평가**: 아래 기준으로 지금 체계를 평가한다. 기준마다 "문제없음" 또는 문제와 그 이유를 쓴다.
2. **이름별 평가**: 그룹 이름 8개와 변주 이름을 하나씩 보고, 그대로 둘지 바꿀지 판단한다. 바꾸자는 이름에만 이유를 쓴다.
3. **대안**: 바꾸자고 한 이름마다 대안을 2~4개 낸다. 대안은 느낌별(예: 설명형, 물건형, 감성형)로 묶고, 각 대안에 장단점을 한 줄씩 붙인다.
4. **추천**: 마지막에 네가 추천하는 최종 목록 하나를 표로 낸다.

## 평가 기준

- **알아보기**: 이름만 보고 화면이 어떤 모습인지, 또는 어떤 장르인지 떠올릴 수 있는가.
- **오해**: 다른 장르나 다른 기능으로 읽힐 위험이 있는가. 예를 들어 "상태창"은 한국 웹소설 독자에게 게임 판타지의 능력치 창을 떠올리게 해서 SF 통신 화면 이름에서 뺐다.
- **짝 맞춤**: 같은 층위의 이름끼리 같은 종류의 말인가. 예를 들어 twin과 solo는 둘 다 "이미지가 몇 개인가"를 말한다.
- **일관성**: 그룹 이름끼리, 변주 이름끼리 말의 종류(물건, 장르, 색)와 길이가 고른가. 한국어와 영어가 섞인 곳이 자연스러운가.
- **길이**: 카드에서 잘리지 않는가. 그룹 이름과 변주 이름을 합쳐 한글 기준 10자 안팎이 좋다.
- **검색**: 사용자가 칠 법한 말("판타지", "SF", "편지", "어두운")로 찾을 수 있는가. 이름에 없더라도 메모 첫 줄에 대상과 분류가 들어간다는 점을 감안한다.
- **겹침**: 서로 다른 그룹이나 변주가 같은 말을 써서 헷갈리지 않는가. 예를 들어 "세피아"는 서재와 파일 두 곳에 있다.

## 지켜야 할 조건

- 형식은 `그룹:이름`을 유지한다. 형식 자체를 바꾸자는 의견이 있으면 할 일 1에 따로 쓴다.
- 실제 앱, 서비스, 상표, 작품 이름을 쓰지 않는다.
- 위의 화면 설명에 없는 기능이나 모습을 전제로 이름을 짓지 않는다.
- 한국어는 합니다체로 쓴다. 번역투(~에 대해, ~을 위한, ~하는 것이다)를 쓰지 않는다. 오타와 띄어쓰기를 다시 본다.

## 결과물

프로젝트 폴더 `risu-theme-preset-v3` 안에 `docs/naming-review.md` 파일 하나를 만든다. 다른 파일은 고치지 않는다. 폴더에 접근할 수 없는 환경이면 같은 내용을 답변으로 낸다.

파일은 다음 순서로 쓴다.

1. 이름 체계 평가 (기준별)
2. 이름별 평가 (그대로 / 바꿈 + 이유)
3. 대안 (바꾸자는 이름마다, 느낌별 묶음과 장단점)
4. 추천 최종 목록 (표)
